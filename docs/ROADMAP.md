# Roadmap

## Milestone 1 — MVP foundation
- [x] Responsive landing page
- [x] Course catalogue API and PostgreSQL seed data
- [x] AI tutor endpoint with demo fallback
- [x] PWA manifest and accessible navigation
- [x] Docker and Render blueprint starter

## Milestone 2 — Learner accounts
- [ ] Register/login/logout
- [ ] Email verification and password reset
- [ ] Role-based authorization
- [ ] Profile and learning preferences

## Milestone 3 — Learning workflows
- [ ] Course modules and lessons in the database
- [ ] Enrollments and lesson progress
- [ ] Quizzes and server-side scoring
- [ ] Course authoring and publishing workflow

## Milestone 4 — AI learning
- [ ] Document upload with file-type and size validation
- [ ] Retrieval augmented generation (RAG) with citations
- [ ] AI quotas, usage tracking, timeout and cost monitoring
- [ ] Tutor evaluation dataset and regression tests
- [ ] Recommendations validated against learner outcomes

## Milestone 5 — Production readiness
- [ ] Isolated code execution sandbox
- [ ] Rate limiting and abuse prevention
- [ ] Security and accessibility review
- [ ] CI pipeline, backups, logs and monitoring
- [ ] Privacy policy, terms, deletion/export workflow
