# OpenCampus AI scorecard

These are product targets, not a verified comparison with W3Schools.

| Area | Weight | Evidence required |
|---|---:|---|
| Context-aware AI tutor | 15 | Answer relevance and groundedness tests |
| Voice-first access | 12 | Browser/device compatibility and usability tests |
| Personalized learning | 12 | Measured recommendation usefulness |
| Coding practice | 12 | Sandboxed execution and automated tests |
| Multilingual support | 10 | Human-reviewed language quality |
| Real-world projects | 10 | Completed learner project rubric |
| Adaptive assessment | 8 | Validated question quality and progress |
| Teacher/institution tools | 7 | Permissions and end-to-end workflow |
| Accessibility and low bandwidth | 6 | WCAG-oriented audit and network testing |
| Security and reliability | 5 | Threat model, tests, monitoring |
| Learning outcomes | 3 | Pre/post learning measurements |
| TOTAL | 100 | Score only after evidence is collected |

Do not assign a competitor an arbitrary score. Use the same rubric, comparable tasks, and transparent evidence for every platform.
